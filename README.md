# UsefulPythonFunctions
## A collection of (maybe) useful functions for your python projects

So, welcome to UPF, or UsefulPythonFunctions. Here you can access 2 .py files to make your life easier (maybe). One of them is the module itself, other one is the checker. 

## Why are you here?

I don't really know. Maybe because you just scrolled through GitHub and found this repository, maybe you looked for Python modules... nvm.

## Can you use it without credits?

Sure. But make sure you DON'T say that it is YOURS, not MINE.

## How do I install it?

Just install usefulpyfunc.py and copy it in into your project's folder.

## How to run it?

Just import. If you don't know how to (really? you're THIS level novice?), here's a tip:
```python
import usefulpyfunc as upf

upf.get_help()
```
